CPUCENTRAL PROCESSING UNIT

电脑的「大脑」

负责计算、执行指令和调度任务，就像导演协调每一个镜头，让电脑有条不紊地工作。

02

内存RAM / MEMORY

临时的「工作台」

放着正在使用的程序和数据，取用很快。但断电后，工作台上的数据就会丢失。

03

存储器SSD / HDD · STORAGE

长期的「收藏柜」

长期保存照片、视频和文件。即使关机，资料也还在，像一个随时可以打开的素材库。

04

操作系统OPERATING SYSTEM

硬件的「管家」

03 / INTERNET ADVENTURE

网络探险

输入一个网址后，网页是怎么来到你面前的？

把访问网站想成一次旅行：打开窗口 → 输入地址 → 查找位置 → 取得内容。

  1. 浏览器

    你看网页的工具，例如 Chrome、Edge。它发送请求，并把收到的代码呈现为文字、图片和页面。

    就像：通往网络的窗口

  2. 域名

    网站方便记忆的名字，例如 example.com。比起一长串数字地址，它更容易让人记住。

    就像：网站的名字与门牌

  3. DNS

    帮你查询域名对应的 IP 地址，让浏览器知道该去哪里找网站。已查过的结果还可以被缓存。

    就像：把名字查成地址的通讯录

  4. 服务器

    一台提供网站服务的计算机。它接收浏览器的请求，把网页文件或所需数据发送回来。

    就像：接单并送出内容的服务站

HTTP / HTTPS：浏览器与服务器的沟通规则

HTTP 规定了请求和响应如何传递；HTTPS 在此基础上增加传输加密与身份验证，就像给内容装上带锁的信封。不过，连接加密并不代表网站内容一定可信。
